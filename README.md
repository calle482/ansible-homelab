# ansible-homelab
This repository aims to contain all my ansible code used for managing and deploying my homelab. As of now it's very W.I.P

# List of goals
* Deployment of virtual machines
* Management of common configuration and patching across all hosts
* Management of application configuration.

# Applications
* Netbox (W.I.P)
* Jellyfin (W.I.P)
* pihole (W.I.P)
* arr-stack (W.I.P)
* qbittorrent (W.I.P)
* Nginx Proxy Manager (W.I.P)
